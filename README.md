## Возможности
-**Отслеживание сохранений:** Плагин автоматически слушает событие сохранения файла (Ctrl+S). Каждый раз, когда вы сохраняете файл, в историю добавляется новая запись.
-**Умный фильтр:** Плагин записывает изменения только для файлов, которые находятся внутри открытой папки проекта. Если вы откроете файл вне проекта, он проигнорирует сохранение, чтобы не засорять историю.
-**Уникальные метки:** Каждой записи присваивается время последнего изменения, иконка дискеты 💾 и метка с относительным путем к файлу (например, «Сохранён test.txt»)
-**Быстрый переход:** При клике на любую запись в Timeline открывается файл, к которому она относится.
-**Защита от потери данных**: История хранится не только в оперативной памяти, но и записывается в файл  внутри вашего проекта.
-**Восстановление после перезапуска:** Когда вы закрываете и открываете VS Code снова, плагин автоматически подгружает историю из history.json обратно в память. Вы не теряете историю при перезапуске редактора.
-**Горячие клавиши:** Назначена комбинация Ctrl+Alt+H (для Windows/Linux), которая работает, когда фокус находится в редакторе кода.

## Требования

-**Среда разработки:** установлена полноценная версия Visual Studio Code версии не менее 1.45
