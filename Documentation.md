# Документация по проекту my-first-extension

## Назначение проекта: плагин для среды разработки Visual Studio Code

## Функции

### `getHistoryFilePath()`

**Файл:** [extension.ts]
**Назначение:** Вычисляет абсолютный путь к файлу истории (.vscode/history.json) в корне текущего открытого проекта.

#### Параметры

Функция ничего не принимает.

#### Возвращаемое значение

| Тип | Описание |
|-----|----------|
| `string` | Строку с путем к файлу, либо undefined, если проект (папка) не открыт. |

**Пример вызова функции**
```typescript
const pathToFile = getHistoryFilePath();
if (pathToFile) {
    console.log(`История хранится тут: ${pathToFile}`);
}
```

### `loadHistoryFromDisk(history: Map<string, vscode.TimelineItem[]>)`

**Файл:** [extension.ts]
**Назначение:** Читает файл .vscode/history.json с диска и восстанавливает из него объекты vscode.TimelineItem, помещая их в переданный Map. Вызывается один раз при старте расширения.

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `history` | `Map<string, vscode.TimelineItem[]>` | Cсылка на глобальное хранилище. |

#### Возвращаемое значение

Функция ничего не возвращает.

**Примеры вызова функции**

```typescript
loadHistoryFromDisk(history);
```


### `appendToDisk(entry: StoredEntry)`

**Файл:** [extension.ts]
**Назначение:** Дозаписывает одну новую запись в файл .vscode/history.json. Если папки .vscode или файла истории нет — создаёт их.

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `entry` | `StoredEntry` | объект с данными о сохранении |

#### Возвращаемое значение

Функция ничего не возвращает.

**Примеры вызова функции**

```typescript
appendToDisk({
    id: "save-99",
    label: "Сохранён test.ts",
    timestamp: Date.now(),
    fileKey: "file:///c%3A/project/test.ts"
});
```


### `activate(context: vscode.ExtensionContext)`

**Файл:** [extension.ts]
**Назначение:** Главная функция расширения. Вызывается VS Code один раз при загрузке плагина. Внутри неё настраивается провайдер Timeline, слушатели событий сохранения и регистрируются команды.

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `context` | `vscode.ExtensionContext` | объект контекста от VS Code, содержит корзину подписок subscriptions  |

#### Возвращаемое значение

Функция ничего не возвращает.

**Примеры вызова функции**

Вызывается автоматически.
